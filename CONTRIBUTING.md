# Contributing to jq

Thanks for wanting to help out!

## Learn

We have an extensive [wiki](https://github.com/jqlang/jq/wiki) covering jq's internals, building, and design. That's the best place to start.

## Process

It's easy: send us a pull request.

- Fix an existing issue, or open one to report a bug or propose an idea.
- Keep pull requests small and focused so they're easy to review.
- Ask questions in the [wiki](https://github.com/jqlang/jq/wiki), on [Stack Overflow](https://stackoverflow.com/questions/tagged/jq), or on [Discord](https://discord.gg/yg6yjNmgAC).
